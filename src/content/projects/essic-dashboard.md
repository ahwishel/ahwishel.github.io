# Crop Planning & Weather Dashboard

At ESSIC, part of the University of Maryland, I built a dynamic management dashboard for crop planning and weather forecasting using React and Material UI. The interactive data visualizations improved data processing efficiency for users by 30% and greatly improved resource allocation.

The dashboard surfaced real-time meteorological data through responsive widgets across mobile and desktop, fed by websocket connections that keep the forecasts current without a page refresh, plus multiple third-party APIs that sync live weather and agricultural data.

This is where the frontend half of my full-stack foundation came from, and it still shows up in how I design agent interfaces today.
